# 📸 Image2PDF – Fast & Secure Image to PDF Converter

![Made with Next.js](https://img.shields.io/badge/Made%20With-Next.js-black)
![JavaScript](https://img.shields.io/badge/Language-JavaScript-yellow)

A clean, lightweight, and secure web application that converts multiple images into a single PDF directly in the browser.

No uploads. No server storage. 100% client-side processing.

---
## 🔐 Privacy & Data Security

Your data is 100% safe.

- This application does NOT upload your images to any server.
- No files are stored in any database.
- No tracking, no analytics, no third-party storage.
- All image processing happens directly in your browser.
- Once the PDF is generated and downloaded, nothing is saved anywhere.

Your images are used only temporarily during conversion.
After download, everything stays on your device.

This tool is built with a privacy-first approach.

## 🎯 Why I Built This

While sharing screenshots, scanned notes, or documents, sending multiple image files becomes messy and unprofessional.

So I built **Image2PDF** — a simple and fast tool that merges images into a clean PDF file in seconds.

This project focuses on:
- Simplicity
- Performance
- Clean UI
- Privacy (client-side processing)

---

## ✨ Features

- 📂 Upload multiple images (JPG, JPEG, PNG)
- 📑 Convert all images into one PDF
- ⚡ Fast client-side conversion
- 🔒 Secure – no backend storage
- 🖥️ Works directly in browser
- 🎨 Clean and minimal UI

---

## 🛠️ Tech Stack

- **Next.js** – Frontend framework
- **JavaScript** – Core logic
- **PDF generation library** – For creating PDF files
- **Modern CSS / Tailwind** – UI styling

---

## 📸 How It Works

1. Upload your images
2. you can rename
3. Click Convert
4. Download your PDF instantly

All processing happens in your browser.
